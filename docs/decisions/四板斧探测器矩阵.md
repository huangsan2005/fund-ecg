四项全中＝过剩行业＋同质化竞争的玩家；四项全不中＝稀缺期卖方。**同一套打法，增长期是战略，停滞期是绝症。**

## 二、成立条件：三条件生态模型

四板斧成立的充分条件不是国籍，是三个结构条件同时成立：

1. **产能过剩＋同质化** → 不抢份额就出清（亏本卖是理性）
2. **资本市场按增长定价** → 份额＝估值＝下一轮融资能力（增长型定价把亏本抢市场变成"股东价值"）
3. **供应商分散且弱＋账期影子银行** → 吃下游是最便宜的融资来源

全球同理：亚马逊亏本卖近20年、美国网约车大战、特斯拉2019年前即"万能融资+赌未来"教科书。中国环境特殊性＝三条件同时成立的行业多、持续久（地方招商激励＋增长型定价＋供应商分散）。**归因到国籍会漏掉退出条件——生态是会变的。**

## 三、免俗检验：宇树为何四项全不中

- ToC+海外零售 → 现金回流周期天然短（没账期可咬）
- 供给稀缺 → 卖方市场不需要拳
- 创始人控制权稳固 → 不被资本推着抢份额
- IPO的钱不是必需 → 不被增长定价绑架

**当产品稀缺时，没人需要打这套拳。**真检验＝人形机器人过剩期（约2028？）宇树打不打。

## 四、生态拆台进行时：比亚迪的历史地位

2025年60天账期新政（比亚迪自己牵的头）＋"反内卷"＝**制度性拆除第三条件**。比亚迪被强制松口的财务代价（一年+794亿有息负债、利息吞噬利润、史上首次净有息负债）＝这套打法头部玩家第一次被要求偿还制度红利。湘德们是尾部（赌输的），比亚迪是头部（赌赢的）——都进同一条退出通道。
