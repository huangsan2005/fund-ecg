# 术语与命名规范

> 本文件是资金心电图对外文档的强制用语标准。公开仓库、交付报告、产品界面一律使用中性术语；本表同时给出"政策型企业"的可量化判定标准，使其成为企业类型学分类而非定性标签。

## 一、政策型企业（Policy-driven Enterprise）

**定义**：生存与发展显著依赖政策环境的企业类型——其现金流结构中，政策性支持（股东结构、订单来源、补贴、融资便利）占比达到可计量水平。

**分类**：

| 子类 | 含义 | 样本 | 心电图特征 |
|---|---|---|---|
| 培育型 | 战略产业扶持，投早投小 | 摩尔线程 | 断粮风险来自造血速度，看"回本日" |
| 纾困型 | 风险处置中的支持 | 万科A | 断粮风险来自支持变量，看"支持存续" |

**判定特征（可量化指纹，满足任意两项即纳入）**：

1. 前十大股东含国资平台、产业基金或下游采购方关联基金
2. 前五大客户收入占比＞50%，且客户具备政策性采购背景（含豁免披露订单）
3. 政府补助、税收优惠占利润总额或盈利预测的比重＞20%
4. 存量融资成本显著低于同评级市场化基准（＞50bp）
5. 存在信创目录、政府采购中标、专项再贷款等政策性渠道记录

**产品映射**：政策性支持强度滑杆（区分培育型/纾困型，算法不同：培育型支持退坡是渐进的，纾困型支持断供是突变的）；咬合率指标；断粮日条件变量。

## 二、中性词对照表（公开文档强制执行）

| 禁用表述 | 中性表述 |
|---|---|
| 政治任务订单 | 政策性订单 |
| 体制内支持强度 | 政策性支持强度 |
| 权力、权力指纹 | 非市场化差异、归因不明 |
| 特权 | 豁免安排、政策性便利 |
| 祭品、被咬死 | 风险集中承担方、受损型交易 |
| 挤供应商 | 延长对上游付款周期 |
| 自家人办事 | 股东与客户身份重叠 |
| 一半批出来 | 含政策性收益因素 |
| 政府关系、暗线 | 政策性支持结构 |
| 僵尸企业 | 保留（官方经济学术语，Caballero-Hoshi-Kashyap定义；中央经济工作会议曾采用），但仅用于技术分析语境 |

## 三、暗处清单管理

承接决策链复核、同债务人执行进度差异比对等暗处评估内容，仅存内部资料，**永不进入公开仓库、产品输出与交付报告**。公开文档至多保留一句中性提示："非市场化差异特征建议追加程序核查。"
