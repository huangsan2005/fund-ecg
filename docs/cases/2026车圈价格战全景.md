## 二、政策时序还原（需求端＋供给端双轨）

```
2025-05-23  比亚迪牵头承诺60天账期（行业引爆点，BYD后5日-13.2%）
2025-06     中汽协倡议书＋经销商商会跟进（口号阶段，市场无视）
2025-07-18  工信部＋发改委＋市监总局三部委座谈（首次部委级）
2025-12     监管细化强化；前10月行业利润率回升至4.4%（拐点确认）
2026-01-01  购置税免征→减半（需求端退坡）＋《价格行为合规指南》实施（供给端动真格）
2026全年    双端夹击下的价格战高潮
2027-12     购置税减半到期（下一个需求端悬崖）
```

**结论：价格战的真正转折不在2026年任何一次降价，在2025-05-23**——比亚迪选择牵头把全行业资金池上交，此后15个月的一切（降价、爆库、砍研发、股价腰斩）都是那笔账的分期付款。

### 渠道库存（流通协会）

2026-03系数1.76→**4月峰值1.89（同比+34%）**→6月回落1.58（仍同比+11.3%）。4月峰值与秦L官降同时点——厂端降价的直接诱因是渠道爆仓。

### 行业产能

2024总产能4,870万辆 vs 销量2,694万辆→利用率**59%**（统计局口径73%；差异=僵尸产能）。仅奇瑞、比亚迪超80%；空置产能约2,000万辆/年的沉没折旧池。

### 规模定量

厂端存货约5,000亿（全行业估）＋渠道压资约5,900亿＋占款模式强制退出——**万亿级营运资金被困**。

## 五、引擎校准（本案例新增）

1. **价格战四指纹**（铁律19复核）：毛利率稳＋量价剪刀差＋研发被动收缩＋存货激增——比亚迪毛利率18.8%纹丝不动骗过第一层，四个科目合谋说谎，资金占用合计不撒谎
2. **政策时点=最大股价事件**：账期新政后5日-13.2%＞任何一次降价的影响。政策公开日是行业级断粮日的钟声，不是利好
3. **倡议≠细则**：市场只定价执法成本，不定价口号成本
4. **官降日≈底部信号**：主动降价=管理层承认现实=不确定性出清；最黑暗的数据改善比最好的业绩更值钱
5. **平台方模式（铁律22）**：谁承压谁承担周期，谁收租谁穿越周期；租户模式的股价弹性最大（赛力斯-65%）
6. **事件-股价四层对齐**成为行业级分析标准模板：政策层×企业层×报表层×市场层，任何单层都会撒谎
