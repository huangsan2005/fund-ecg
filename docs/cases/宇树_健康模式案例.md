# 宇树科技：健康模式观察清单（首个市场化成长样本）

> 三样本中唯一"不缺钱"的公司。无断粮日风险，观察主题从"还能撑多久"转为"健康能维持多久"。底稿：YS_招股书（2026-08-14披露，容诚审计，标准无保留意见，2025-10-15出具）。

## 二、口径备忘（读数前必看）

1. 扣非5.91亿的"漂亮"含口径选择：2025年6月员工激励平台增资确认3.49亿股份支付费用计入非经常性损益（依据2023年修订的《非经常性损益解释性公告》，合规）。读真实盈利能力时应加回：真实经营净利率约33%（报表显示35%+）。未来若有大额激励授予，扣非与归母将再度背离，同口径处理
2. 装配环节劳务外包（年费0.12→0.22→0.68亿）：轻资产选择，品质管控是隐性风险点
3. 一季度逆风属冲刺回落：2026Q1经营现金流同比-85.7%（备货+春晚营销），扣非指引同比-6%~-22%

## 三、核心观察命题：8.5%研发费率能否守住下一个技术代际

宇树当前利润建立在"现在的机器人"（四足+G1现货）之上。人形机器人下一阶段竞争（大模型大脑、灵巧手、通用操作）的研发烧钱量级完全不同——研发费率8.5%在具身智能赛道属反常地低。两种解释并存：技术复用率高（四足→人形组件通用）+春晚免费流量；或投入不足、赌下一个代际。59亿募资全部投向模型研发+本体研发+新产线，本身就是管理层对"钱该去哪"的回答。

**观察的本质：一家靠毛利率活着的市场化公司，何时被军备竞赛拖回"需要融资"的形态。**

## 五、与另两样本的关系（引擎分诊逻辑）

| | 万科 | 摩尔线程 | 宇树 |
|---|---|---|---|
| 分型 | 纾困型政策企业 | 培育型政策企业 | 市场化成长企业 |
| 引擎模式 | 僵尸模式（断粮日） | 回本日模式（融资窗口） | **健康模式（分诊后免CT）** |
| 核心监控 | 支持断供 | 融资依赖度递减 | 毛利率守卫+研发代际 |

健康模式判据（任一失效即降级重检）：经营现金流为正、补助依赖<10%、客户离散（Top5<30%）、无有息负债依赖、融资间隔>18个月。**产品不是把所有公司都往病床上按——先分诊，健康人不做CT。**
