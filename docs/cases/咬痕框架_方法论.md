# 咬痕框架：僵尸化诊断与暗处观察（方法论篇）

> 从万科案例延伸出的三模块框架：开发侧（僵尸本身）、债权侧（猎物预警）、被咬企业侧（对手方咬痕扫描）。本文记录框架定义与暗处边界，供引擎实现参考。

## 一、僵尸化的经济学定义

Caballero-Hoshi-Kashyap三要件：资不抵债＋靠债权人非市场化续命存活＋债权人权利被扭曲。中国变奏比日本模式更稳定：日本银行自愿输血（怕坏账暴露），中国是行政强制输血＋债权人程序暂停——没有一个债权人能退出。

## 二、咬合率指标（引擎可实现，全部来自A级现金流量表）

**咬合率 =（展期＋股东借款＋应付账款压降＋政策性续贷）÷ 总流入**

万科2026H1测算：展期181亿＋深铁45亿＋延长对上游付款周期143亿＋政策性融资41亿≈410亿；自愿性流入（卖房358亿＋经营服务180亿）≈540亿。咬合率约四成，只看开发主业过半。**超过50%不再是"现金流紧张"，是"僵尸化确诊"。**

## 三、被咬者的传染机制

僵尸状态通过资产负债表传染：被咬企业资产端挂着被冻结的应收（死资产），负债端欠着自己的上游（活债务）。存活前提是把自己转化成僵尸——用自己能欠的账替换收不回的账；不转化的当场吃损失，重伤者流动资金扛不住直接死。**法律程序是经济免疫系统，暂停执行等于免疫抑制——免疫抑制下的感染不自愈，只扩散。**

被咬者的死亡是静默的：不进任何统计。头部房企应付＋其他应付款万亿级贸易债权处于冻结状态（C级粗算），没人给被咬者建档。

## 五、暗处边界（产品红线）

1. 数据能显示"非市场化差异"，不能完成归因——工具输出若含归因表述即构成不当指控
2. 职业怀疑是审计师的判断，算法不下定性结论
3. 显性化、产品化的判断会让工具本身进入被照者的视野

工程形态：**红旗问题清单**——不打分、不进仪表盘、不进任何导出报告；触发后仅在底稿附注区生成中性程序建议（对手方涉执核查、同债务人执行进度比对、承接决策链复核、承接时点与对手方融资节点相关性）；语言永远"建议关注"，永不出现定性指控词。

一句话归档：**明处引擎算洞，暗处清单看手。**洞的大小决定资产值多少，手的方向决定这家企业还能不能碰。

## 六、对手方咬痕扫描（被咬企业侧模块）

输入：应收台账＋前十大客户名单。
引擎动作：扫描每个对手方公开痕迹（被执行、股权冻结、票据逾期名单、协调机制、诉讼激增）→ 咬痕分级 → 应收真实价值重估。

咬痕科目定位（隐蔽度排序）：
- 应收账款/票据：三件套全部失效——函证确认"存在"不确认"可收回"；账龄被展期协议刷新清零；ECL模型没有"行政冻结"参数
- **存货（以房抵债）**：最隐蔽的咬痕，按抵债面值挂账，实为烂尾楼；税务上二次受损
- 其他应收款、合同资产：停工项目的死资产

有效程序：**期后回款测试**（资产负债表日后三个月，骗不了人）＋净利润与经营现金流的剪刀差（开票即确认收入照常缴税，利润是观点现金是事实）。

## 七、定价

**咬痕规模 ≈ 应收账面值 ×（1 − 预期回收率）**

预期回收率参照系：活债90%+、病债50~70%、僵债（协调机制/展期中）10~30%、死债（破产受理）3~8%。**保理市场折价率是它的市场报价**——债权包在AMC手里打几折，账面就该认几折。

客户：银行授信（第一还款来源监测）、并购尽调、评估机构、审计事务所（计提充分性）。60案库的死房企债权人名册＝预期回收率的经验数据来源。

## 八、口径纪律（3.02%教训）

任何单一披露数字都可能是口径产物：名义综合融资成本3.02%（时点加权票面价）vs 有效利率3.5%~3.7%（期间实际计息）相容并存；困境期融资成本显著优于市场基准＝**非市场性支持**的指纹（便宜的钱是最贵的那种，断的时候一夜之间）。同名指标必须分口径分栏，溯源面板四行：原文引用（A级）→ 未审计章节/口径自定（B级）→ 内部交叉验证 → 同业对照等级。
