# 资金心电图（Fund ECG）

AI驱动的企业资金流模拟、推演与预警工具。把银行流水和合同变成一张资金曲线图，让决策者在断粮之前看到断粮日。

## 一句话定位

让决策者像玩游戏一样模拟资源配置：拖动滑杆，看资金曲线实时变形，看断粮日和回本日两个日期如何变化。所有推理白箱可溯，所有输入数据按可信度分级打分。

## 核心概念

### 三条资金曲线

1. 历史真实曲线——来自银行流水（真值锚）
2. 未来义务曲线——来自合同付款节点排布
3. 预算曲线——来自企业预算（愿望，降权处理）

### 英雄指标：两个日期

- **断粮日**：资金余额首次穿零的日期
- **回本日**：累计资金流转正的日期

所有滑杆操作映射为这两个日期的天数变化量。决策者记日期，不记金额。

### 健康分

未来90天义务覆盖率 = 可用资金 / 刚性支出。一屏一数一色（绿/黄/红）。

### 六类死亡剧本（风险分类学）

| 编号 | 剧本 | 锚点案例特征 |
|---|---|---|
| S1 | 抽逃断链型 | 贷款到账当天转往体外、监管户被抽动 |
| S2 | 扩张失血型 | 预售资金买地、极速扩张 |
| S3 | 高息拖垮型 | 民间借贷登场、商票连环、融资质量降级 |
| S4 | 合同义务失控型 | 短债与现金缺口撕裂、付款节点遗忘 |
| S5 | 账期漂移型 | 应付账期持续拉长、挤占供应商 |
| S6 | 停工空转型 | 纯消耗性支出占比上升、监理费拖成僵尸费用 |

剧本同时用作：预警分类、流水打标体系、反方唱票规则、案例归档结构。

### 数据质量四级评分（ABCD）

- A级：±15天预测区间
- B级：±45天
- C级：±120天
- D级：不出预测，只给体检清单

宁可不算，不可乱算。数据质量评分影响预测区间宽度、预警强度和白箱展示深度。

## 设计铁律

1. **现金为王**：唯一主线是资金余额曲线。利润是观点，现金是事实。
2. **英雄指标是日期不是金额**：断粮日 + 回本日。
3. **银行流水为锚、合同为义务源**：目标客户大多没有规范三张表；流水是唯一造假困难的真值锚。
4. **数据质量闸门输出**：ABCD分级决定预测是否出具。
5. **预测能力永远不免费**：免费版仅浅体检（打标+评分+健康分）；免费送出错的预测会无声砸招牌，白箱才可辩护。
6. **LLM零数值铁律**：LLM只做意图理解、标签建议、话术组织、反方唱票质疑；进入计算的每个数字来自确定性引擎。
7. **案例先验库是护城河**：行业基准值、贝叶斯先验、死亡剧本阈值由真实审计案例校准；客户数据永不进共享库。

## 方法论验证：万科A案例

产品核心算法（义务覆盖率 + 毛现金流 + 断粮日条件变量）已用上市公司公开数据做了一轮完整闭环：基于2025年年报做推演，用2026年一季报和半年报逐项验证。

详见 [docs/cases/万科A_断粮日推演与验证.md](docs/cases/万科A_断粮日推演与验证.md)

关键结论：连A股披露标准（数据质量A级）的诚实公司，期末现金余额都在说谎——现金余额672亿到590亿看着稳定，实际是181亿债务展期、45亿股东借款、143亿挤占供应商凑出来的静态平衡。毛现金流才是心电图，期末数只是截图。
